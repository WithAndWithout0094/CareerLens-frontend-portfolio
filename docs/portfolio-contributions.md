# 개인 기여 범위

이 저장소는 **신영석의 AI 활용 프론트엔드 포트폴리오 및 개인 배포본**입니다. UI 개발과 서버 연동을 주 작업으로 삼았으며, AI 도구를 구현·점검 과정에 사용했습니다.

## 프론트엔드

- 이력서 입력, 희망 직무, 공고 탐색, 분석 로딩, 보고서 조회를 연결하는 화면과 모션.
- 처음 접속했을 때 바로 보이는 프론트엔드 포트폴리오 소개와 개인 배포 표시.
- 모든 페이지에서 기능 설명을 함께 표시하고 클릭·Escape로 닫는 안내.
- 원래 분석 로딩과 결과 화면을 유지하면서 이용 흐름을 별도 창으로 제공.
- 대시보드·실시간 다중 사용자 관찰, 이용 흐름 카드 41개에서 29개로 통합.
- 실제 프로젝트 가상 이력서 파일을 선택·무작위 체험에 연결.

## 기존 백엔드와 추가 수정

기존 팀 저장소 `931njhthe-star/CareerLens-fullstack`의 통합본을 기반으로 했습니다. 기존 인증·DB 모델·LangGraph 평가 흐름·채점·보고서 생성은 팀 백엔드 작업자의 결과물입니다. 기존 Git 기록에서 백엔드 변경은 `hunhun` 등의 작성자로 남아 있으며, 본 포트폴리오는 그 구현을 본인의 단독 작업으로 소개하지 않습니다. 개인 통합 작업 시작점은 `8b6b5143fa28b083a63926017a416a1d78948421`입니다.

| 변경 | 해결하려는 문제 |
| --- | --- |
| 제한된 수의 비동기 평가 작업을 함께 실행 | 한 분석이 끝날 때까지 다음 요청이 대기하던 워커 구조 |
| 실행별 lease·heartbeat·취소·종료 처리 유지 | 동시 실행 시 중복 처리나 서로 다른 결과의 혼합 방지 |
| Redis에 개인정보 없는 실행 상태 공유 | 여러 사용자의 서버 실행 상태를 관찰 |
| PostgreSQL 상태로 복원 | 무료 Redis 재시작으로 캐시가 없어져도 회원 실행 기록 유지 |
| 공개 지표와 비공개 자료의 서버 분리 | 공개 체험에서 개인 이력서·점수·모델 응답 원문 노출 방지 |
| 실행 보고서의 운영 지표 연결 | 기존 로컬 실행 기록과 배포 서버의 새 실행 기록을 대시보드에 표시 |
| 가상 이력서 카탈로그 API | 고정된 한 예시 대신 프로젝트에 있는 가상 이력서 파일 사용 |
| 개인 배포 bootstrap·추가 마이그레이션 | 기존 DB를 덮어쓰지 않고 개인 서비스의 필요한 데이터 구조 준비 |
| 서버 요청 제한 | 공개 체험을 통한 개인 API의 과도한 사용 억제 |

동시 처리 수는 서버 자원과 모델 제공자의 허용량 범위에서 제한합니다. 단순히 로딩 화면 여러 개를 보여주는 것으로 동시 분석 성공을 판단하지 않습니다. 테스트에서 작업 시작 시간이 겹치는지, 사용자별 상태와 결과가 분리되는지를 확인합니다.

## 개인 배포

- 소스: `WithAndWithout0094/CareerLens-frontend-portfolio`
- 웹: <https://careerlens-personal-web.onrender.com>
- 개인 Render 작업공간에 웹 서비스, PostgreSQL, Redis 호환 Key Value 구성.
- 개인 배포본을 구성하며 기존 팀 서비스의 운영 DB를 변경하지 않습니다.
- 자격증명과 운영 원문은 Git에서 제외. 기존 실행 기록은 시간·호출 수 등 허용된 지표만 가져옵니다.

무료 PostgreSQL의 유효 기간과 무료 서비스의 휴면·자원 제한은 Render 계정에서 관리해야 합니다. 비회원의 임시 보고서는 영속 회원 보고서와 보존 범위가 다릅니다. 모델 크레딧 부족과 제공자 오류는 실제 실패로 안내하며, 임의 점수로 대체하지 않습니다.
